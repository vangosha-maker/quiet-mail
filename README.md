# Тихая почта

Пошаговая головоломка. На поле 5×5 или 6×6 лежат источники писем, ящики и стены. Нужно проложить ленты так, чтобы каждое письмо доехало до ящика своего цвета и своей формы.

В игре нет случайности, таймера, сети, аналитики и аккаунтов. Стрелочники, перекрашивание и оценка марками не входят в этот MVP.

## Правила

Письмо выезжает из источника в указанную сторону и на каждом шаге переходит в соседнюю клетку по ленте. Прямая везёт дальше по той же оси, поворот сворачивает на 90 градусов. Мост-развязка держит две ленты в одной клетке: горизонтальная и вертикальная не сталкиваются.

«Запустить» проигрывает доставку до конца. «Шаг» показывает один ход всех писем сразу. Успех — все письма в своих ящиках. Первая ошибка останавливает разбор и подсвечивает клетку:

- тупик — лента оборвалась или упёрлась в стену;
- чужой ящик — письмо приехало не по адресу;
- столкновение — два письма претендуют на одну клетку или на одну полосу моста;
- выход за поле — лента уводит за край.

## Управление

- Клик или тап по пустой клетке меняет деталь по кругу: пусто, горизонталь, вертикаль, четыре поворота, мост.
- Протяжка мышью или пальцем рисует ленту. Если новая лента пересекает уже лежащую прямую, клетка становится мостом.
- Кнопки: «Запустить», «Шаг», «Отменить», «Заново». Уровни переключаются кнопками над полем.
- Клавиатура: стрелки двигают курсор, Enter или пробел меняет деталь в клетке курсора.

Прокрутка страницы отключена только на поле (`touch-action: none`). Вне поля страница прокручивается как обычно.

Письма различаются и цветом, и формой: красное круглое, синее квадратное, зелёное треугольное. Статус дублируется текстом в области с `aria-live="polite"`.

## Сохранение

В этом браузере запоминаются текущий уровень, пройденные уровни и черновик раскладки вместе с отменой хода. После перезагрузки можно продолжить. «Заново» очищает только текущий уровень.

Если хранилище недоступно или переполнено, игра продолжается без сохранения. Битые или несовместимые данные сбрасываются к началу первого уровня и не роняют страницу. Сохранения не уходят на сервер.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server --directory dist
```

Если команда называется `python3`, подставьте её. Откройте http://127.0.0.1:8000/ . Остановка сервера — Ctrl+C. Сервер нужен только чтобы браузер загрузил ES-модули. Сборка и установка зависимостей не требуются.

`docs/` повторяет `dist/` и оставлена для возможной публикации. GitHub Pages этой веткой не включается.

## Тесты

Из корня репозитория:

```sh
node --test tests/*.test.js
```

или `npm test`. Проверяются движок, решаемость шести уровней эталонными раскладками, сохранение и базовый интерфейс без браузера. Пропусков нет.

Отдельный браузерный прогон, не входящий в `node --test`:

```sh
node tests/browser-qa.mjs
```

Скрипт сам поднимает временный сервер из `dist/`, открывает системный Chrome (или Playwright, если он установлен) и проверяет поле на 360×640 и 390×844: нет горизонтальной прокрутки, поле, статус и кнопки не перекрываются, клетки не меньше 44 px, протяжка по полю не прокручивает страницу. Скриншоты пишутся в `/tmp/quiet-mail-qa`.

`python tests/browser-qa.py` запускает тот же сценарий через Node.
